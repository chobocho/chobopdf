chobopdf 작업 이력

2026-10-10 설계

  • 목표: 300~500MB 대용량 PDF의 페이지 이동, 회전, 삭제, 복사, 추가를 썸네일 드래그로 처리하는 Windows 데스크톱 툴.
  • 언어/라이브러리 결정: Python 3.12, PySide6(GUI), pikepdf(편집·저장), pypdfium2(썸네일 렌더링).
  • 핵심 설계: 편집은 메모리의 페이지 목록(PageRef)만 변경하고 PDF 쓰기는 저장할 때 한 번만 수행.
  • 썸네일: 저해상도로 화면에 보이는 페이지만 백그라운드 렌더링, LRU 캐시, 회전은 재렌더링 없이 그릴 때 변환.
  • 저장: 작업 스레드에서 임시 파일에 쓴 뒤 교체, 진행률 표시와 취소 지원.
  • 상태: 설계 제안 완료, 구현은 아직 시작하지 않음.
