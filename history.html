2026-10-11 Ctrl+0, Ctrl+9를 창 어디서나 동작하게 함

  • 요청: "전체화면에서 Ctrl+0, Ctrl+9가 먹게 해줘". 앱에 별도의 전체화면 모드는 없으므로, 미리보기를 클릭해 포커스를 주지 않아도 창 전체에서 동작하게 해 달라는 뜻으로 해석함.
  • 원인: 폭 맞춤(Ctrl+0)과 쪽 맞춤(Ctrl+9)은 미리보기 스크롤 영역의 키 이벤트 필터에서만 처리되어, 더블 클릭으로 미리보기를 연 직후처럼 포커스가 썸네일 격자에 있으면 동작하지 않았음.
  • 수정: main_window.py에 창 전체에 적용되는 QShortcut 두 개(Ctrl+0, Ctrl+9)를 추가. preview_pane.py에 공개 메서드 fit_to_width, fit_to_page를 만들어 버튼, 키, 단축키가 같이 씀. 미리보기가 닫혀 있으면 아무 일도 하지 않음.
  • 확대/축소(Ctrl++ / Ctrl+-)와 페이지 이동 키는 이전처럼 미리보기에 포커스가 있을 때만 동작(요청 범위 밖이라 그대로 둠).
  • F1 도움말의 참고 문구, README.md, README.ko.md의 미리보기 설명을 이에 맞게 고침.
  • test_preview.py: 썸네일 격자에 포커스가 있을 때 Ctrl+0, Ctrl+9가 동작하는지 확인하는 단계를 추가(수정 전 코드에서는 실패함을 확인).
  • 검증: 단위 테스트 71개 통과. 실제 창에서의 키보드 조작은 확인하지 않음. exe 재빌드와 커밋은 하지 않음.
  • history.html이 30KB에 가까워 이전 이력을 history_20261011_184347.html로 백업하고 새로 시작함.

2026-10-11 Tab으로 썸네일과 미리보기 사이 포커스 이동

  • 요청: Tab으로 페이지 뷰(썸네일 격자)와 렌더링 뷰(미리보기) 사이에서 포커스가 이동해야 함.
  • 원인: Tab 순서에 상태 표시줄의 썸네일 크기 슬라이더가 끼어 있어, 썸네일 → 미리보기 → 슬라이더 → 썸네일 순으로 돌았고 미리보기가 닫혀 있을 때는 슬라이더로 포커스가 빠졌음.
  • 수정: main_window.py에서 슬라이더의 포커스 정책을 클릭 전용(ClickFocus)으로 바꿈. 이제 Tab / Shift+Tab이 썸네일과 미리보기 사이만 오가고, 미리보기가 닫혀 있으면 포커스는 썸네일에 머묾. 슬라이더는 마우스로 클릭하면 이전처럼 키보드로도 조절 가능.
  • Tab으로 미리보기에 포커스를 옮기면 Page Up / Page Down, 화살표, Ctrl++ / Ctrl+-가 클릭 없이 바로 동작. 미리보기를 닫으면 포커스는 썸네일로 돌아감.
  • F1 도움말, README.md, README.ko.md에 Tab 항목 추가. test_preview.py에 Tab 이동 테스트 1개 추가.
  • 검증: 단위 테스트 72개 통과. 실제 창에서의 키보드 조작은 확인하지 않음. 어느 쪽에 포커스가 있는지 보여 주는 표시는 따로 추가하지 않음. exe 재빌드와 커밋은 하지 않음.

2026-10-11 Ctrl++ / Ctrl+-를 창 어디서나, 썸네일에서 Enter로 미리보기 열기

  • 요청: 확대/축소 키(Ctrl++, Ctrl+-)도 창 어디서나 동작하게 하고, 썸네일 창에서 Enter를 치면 페이지 보기(미리보기)가 열리게 함.
  • 확대/축소: main_window.py의 창 전체 단축키에 Ctrl++, Ctrl+=, Ctrl+-를 추가(Ctrl+0, Ctrl+9와 한 묶음). preview_pane.py에 공개 메서드 zoom_in, zoom_out을 만들어 버튼, 키, 단축키가 같이 씀. 이제 미리보기 전용으로 남은 키는 페이지 이동(Page Up / Page Down, 화살표)뿐.
  • Enter: 썸네일 격자에 포커스가 있을 때 Enter(숫자 키패드 Enter 포함)를 누르면 현재 페이지의 미리보기가 열림. 더블 클릭과 같은 동작이며 포커스는 썸네일에 남음(미리보기로 가려면 Tab). 현재 페이지가 없으면(문서가 없거나 아무것도 고르지 않음) 열지 않음.

  • 검증: 단위 테스트 74개 통과. 테스트는 합성 키 이벤트를 쓰므로, 실제 키보드에서 Shift를 함께 눌러 입력하는 Ctrl++(Ctrl+Shift+=)는 확인하지 못함. 실제 창에서의 조작도 확인하지 않음.
